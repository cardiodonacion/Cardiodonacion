RECURRENTES — SITIO WEB
========================

CONTENIDO
- index.html: sitio web completo (HTML, CSS y JavaScript integrados).

PUBLICAR EN GITHUB PAGES
1. Descomprime recurrentes_web.zip.
2. En GitHub crea un repositorio público, por ejemplo: recurrentes.
3. Sube index.html a la raíz del repositorio.
4. Ve a Settings > Pages.
5. En "Build and deployment", selecciona "Deploy from a branch".
6. Selecciona la rama main y la carpeta /(root), guarda.
7. GitHub mostrará la URL pública cuando termine la publicación.

PERSONALIZACIÓN PENDIENTE ANTES DE PRESENTAR A WOMPI
- Completar la descripción exacta de los servicios realmente prestados.
- Verificar que la actividad ofrecida coincida con el RUT y con la información declarada ante Wompi.
- Publicar una política completa de tratamiento de datos personales y condiciones de contratación ajustadas al negocio.
- Confirmar que dirección y teléfonos estén correctos.
- Si se agrega correo electrónico, reemplazar el dato en la web por el correo real.

IMPORTANTE
El chat es un asistente automático local con respuestas predeterminadas. No utiliza IA, no guarda conversaciones y no transfiere mensajes a un operador. Los botones de WhatsApp abren conversaciones externas. La web no procesa pagos ni solicita datos de tarjetas.
